# Jornada do Cerebro da Robo

## Principio

Antes de pensar em rodas, corpo ou rosto humanoide, o projeto precisa ter um bom cerebro: informacoes confiaveis, bem organizadas e faceis de atualizar.

## Fase 1 - Base confiavel

Criar uma base de conhecimento com respostas curtas, fontes internas e responsaveis por validacao.

Cada informacao deve ter:

- tema;
- pergunta ou intencao;
- resposta;
- palavras-chave;
- setor responsavel pela informacao;
- data de revisao;
- status: rascunho, revisado ou publicado.

## Fase 2 - Buscador simples

Antes de usar IA, usar busca por palavras-chave para responder perguntas comuns. Isso ajuda a descobrir quais informacoes faltam e quais perguntas as pessoas realmente fazem.

## Fase 3 - Interface de atendimento

Criar uma tela com:

- campo de pergunta;
- botoes por categoria;
- respostas claras;
- opcao "nao encontrei minha duvida";
- encaminhamento para setor responsavel.

## Fase 4 - IA com seguranca

Adicionar LLM somente depois que a base estiver organizada. A IA deve responder com base nos documentos oficiais e, quando nao souber, dizer que nao encontrou a informacao.

## Fase 5 - Corpo fisico

Depois que o atendimento funcionar bem, decidir entre:

- totem fixo com tela;
- tela com face animada;
- robo semi-humanoide fixo;
- robo movel com rodas.

Minha recomendacao inicial: totem fixo com tela touch.
